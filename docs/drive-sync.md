# Googleドライブ同期（お試し版）

スマホ・タブレット・Surfaceで、同じGoogleアカウントを使って部材や書類を揃えます。業務Proの自動同期と同じ考え方です。

## 使い方（各端末で同じ）

1. お試し版のページを開く（本番のURLとは別です。オレンジの「お試し版」が表示されます）。
2. 画面上部の **「接続して同期」** を、アプリを開くたびに1回押します。
3. 初めての端末では、接続用クライアントIDを求められたら、業務Proで使っているもの（末尾が `.apps.googleusercontent.com`）を貼ります。パスワードやシークレットは不要です。すでに業務Proを同じブラウザで使っていれば、自動で使えます。
4. Googleの画面で、同じGoogleアカウントを選び、アプリ専用領域へのアクセスを許可します。
5. 初回は合わせる前に、この端末の控えを取ります。「初回同期前の控えを書き出す」から保存できます。
6. 接続したあとは、変更の約2秒後に自動で同期します。オフラインでもこの端末への保存は今までどおり動きます。つながったときに揃えます。

## 同期されるもの

- HW部材表（名前・単価・数量・在庫など）と、保存した過去の集計
- 一般モードの部材マスター
- 見積書・請求書
- 自社情報（会社名・住所・インボイス登録番号・ロゴなど）
- HW集計表の宛先・発行元

## この端末だけに残るもの

- **工事価格表**（Excelから読み込んだ価格。他の端末には送りません）
- 画面の開閉や、最後に選んだモード
- Googleの接続トークン（画面を開いている間だけメモリに持ち、保存しません）
- 同期の内部記録、各種バックアップ控え

## 両方の端末で別々に直したとき

違う項目（例: 片方は数量、もう片方は名前）なら両方残ります。同じ項目を両方で直したときは、あとに直した方が残ります。初回に同じ部材で中身が違うときは、空欄でない方を採用します。

## まとめて消えてしまったとき

この端末で部材・集計・書類が5件以上（かつ全体の3割超）まとめて消えていると、同期は止まって確認します。

- OK: もう1台からも消す
- キャンセル: 消さずに、もう1台から戻す

## うまくいかないとき

- 帯が赤または黄で理由を出します。失敗しても、この端末の保存データは消しません。
- 接続が切れたら「接続して同期」をもう一度。
- `origin_mismatch` と出たら、Google Cloud の「承認済みの JavaScript 生成元」に `https://akiyamanx.github.io`（末尾スラッシュやパスは付けない）があるか確認してください。業務Proで登録済みなら、追加は不要な見込みです。
- Drive API がプロジェクトで有効になっている必要があります（業務Proで使えていれば、そのままです）。

## 技術メモ

- 保存先は Google Drive のアプリ専用領域（通常のファイル一覧には出ません）。
- ファイル名の印は `HWPartsDataSync1` / `HWParts-data-` / channel `hw-parts-staging`（お試し）または `hw-parts-main`（将来の本番用）。業務Pro（`CULOchanDataSync1` 等）とは混ざりません。
- お試し版の localStorage キーには接頭辞 `stgHw:` が付き、本番の保存データには触れません。
