# HW部材集計アプリ

HYPER Water（HW）の設置工事で使った部材と数量を集計し、マーフィード送付用の集計表（PDF）まで出力できる、スマホ向けの単一HTMLアプリ。

## 概要

- 株式会社AKC Total Support の現場業務用ツール
- スマホのブラウザだけで動く（インストール不要・単一HTMLファイル）
- 「HW工事材料.xlsx」の **131部材** を10カテゴリに分けて初期搭載

## 主な機能

- **カテゴリ別リスト**：HIVP / 鋼管 / バルブ / ホースニップル / フレキニップル / 固定足・バンド / 基本水栓・継手 / 電気部材 / その他 / 別注文（折りたたみ＋部材名検索）
- **個数部材**：単価 × 数量（プルダウン 0〜50）＝ 金額
- **長物部材**（配線・ホース・巻物）：購入金額 ÷ 購入長 ＝ 1m単価、使用m × 1m単価 ＝ 金額
- **単価の編集**：各部材の単価・購入金額・購入長を編集でき、個数⇔メートルの切り替えも可能（価格変動に対応）
- **合計バー**：画面下に小計・消費税（変更可・初期10%）・総合計を常時固定表示
- **新規部材の登録／削除**
- **集計のテキストコピー**（LINE等に貼り付け用）
- **印刷用集計表**：マーフィード御中の宛名・AKC発行で表組み表示 →「印刷/PDF」でリコー等のコピー機アプリからPDF化
